DeepSeek `deepseek-v4-flash` (accessed via [OpenRouter](https://openrouter.ai)) receives the earnings-call fact summaries disseminated to competition participants and predicts the stock's post-call abnormal return as a direction (up/neutral/down) and a cross-sectional percentile.

| Category | Classification |
| --- | --- |
| Approach | LLM / GenAI |
| Models | DeepSeek |
| Information set | competition facts |
| Learning / adaptation | zero-shot / prompted |
| Agent architecture | single-pass |
| Prediction construction | direct LLM score |

## What is predicted

The **unexpected (abnormal, market-adjusted) stock return on the trading day following the earnings call**. The model emits three fields:

- `predict_class` ∈ {`up`, `neutral`, `down`}, defined as +≥5% / within ±5% / −≥5% moves (target class balance ~25/50/25%).
- `predict_percentile` ∈ [0, 1]: the return's percentile in the cross-section of all events.
- `rationale`: a 2–3 sentence justification referencing substantive evidence.

Only `predict_percentile` is submitted to the competition (clamped to [0, 1], divided by 100 if the model answers on a 0–100 scale); the class and rationale are logged.

## Input context

Exactly what every participant receives: the key-fact summary from the event's disseminated `DisclosureBundle`, rendered as a bullet list. The model does **not** see the raw transcript, and no market/price data, analyst estimates, web access, or tools are provided.

## Model & harness

- **Model:** `deepseek-v4-flash` (DeepSeek), accessed via OpenRouter as `deepseek/deepseek-v4-flash`.
- **Framework:** DSPy. The predictor is a `dspy.ChainOfThought` over the signature below, so the model additionally emits a free-text `reasoning` field before the structured outputs.
- **Hyperparameters:** `temperature = 1.0`, `top_p = 1.0` (DeepSeek's recommended values, pinned explicitly; the model ignores sampling parameters while thinking), reasoning effort `high`, `max_tokens` unset. Response caching disabled (a fresh model call each time), so outputs remain stochastic across runs.
- **Live operation:** the worker receives each event at broadcast (webhook) and submits the percentile from a single model draw. Output the model returns but the harness cannot parse falls back to a neutral 0.5 submission.

## Representative prompt

The prompt is generated by DSPy from the signature: the docstring is the task instruction, the input field carries the summary, and the output fields define the required response schema.

```
Predict the unexpected stock return following an earnings call.

You are given key facts from a company's earnings call transcript.
Predict the stock's unexpected return as a class and percentile.

Base rates — calibrate your predictions to these proportions:
  - ~25% of stocks go UP (price increases 5%+ after the call)
  - ~50% of stocks are NEUTRAL (price moves less than 5%)
  - ~25% of stocks go DOWN (price decreases 5%+ after the call)

Consistency constraints between class and percentile:
  - "down"    → percentile in [0.00, 0.25]
  - "neutral" → percentile in [0.25, 0.75]
  - "up"      → percentile in [0.75, 1.00]

--- Inputs ---
key_facts_discussed_in_earnings_call: Bullet-point summary of key facts
                                      from the earnings call

--- Outputs ---
predict_class:      Literal["up", "neutral", "down"]
predict_percentile: float — 0.0 (worst) to 1.0 (best)
rationale:          2-3 sentence explanation using substantive evidence
```

## Data flow

Disseminated fact summary (webhook) → bullet-list rendering → `deepseek-v4-flash` via OpenRouter (`ChainOfThought`) → `{predict_class, predict_percentile, rationale}` → percentile submitted.

## Limitations

- Prediction quality is bounded by the disseminated summary; the raw transcript is never seen at prediction time.
- No market/price context, analyst estimates, or web access.
- Provider-default sampling makes outputs stochastic; the same input can yield different predictions across runs.
- OpenRouter may serve a request from any of the model's upstream providers, and a retried call can land on a different provider than the first attempt.
